# My Little Space
明亮奶油米白＋粉紫藍綠柔和漸層。
食物：日式、韓式、義式、咖啡廳、餐酒館、其他。
購物：台灣、日本、其他。
影劇：韓劇、陸劇、電影。
生活管理：提醒事項、行程。
不包含 App／桌面捷徑功能。


使用者名稱：每個帳號預設顯示 `user`，可由使用者自行修改；修改後只保存於自己的帳號。


### 最新設定
- 生活管理圖示：🧩
- 食物分類：日式、韓式、義式、咖啡廳、餐酒館、其他
- 購物分類：台灣、日本、其他
- 影劇分類：韓劇、陸劇、電影
- 食物包含備註、捷運站、出口、步行時間與 Google Maps
- 新帳號名稱預設為 `user`，可自行修改
- 分享連結預覽文案：收藏一些喜歡，把想記得的都留在這裡。登入後就可以開始使用 ♡


## v10 更新
- 生活管理新增開始日期／結束日期，可顯示日期區間，例如 8/27 ～ 9/3。
- 修正 todos.done 欄位相容性。
- 食物走路資訊圖示改為 🚶🏻‍♀️。
- 修正購物清單依 country 分類讀取，避免資料存了卻不顯示。
- 所有新增、編輯、刪除都以目前登入帳號的 user_id 寫入／篩選。


## v11 修正
- 修正按「編輯」時因資料 ID 型別不一致，導致找不到原資料而出現空白表單的問題。
- 現在編輯時會自動帶入原本儲存的內容，再進行修改。


## v13 修正
- 生活管理的開始日期、結束日期、時間全部改為非必填。
- 欄位留白時會送出 null，不會再因空白日期／時間造成資料庫型別錯誤。
- 仍可只填其中一個日期；只有開始與結束日期都填寫時才會檢查先後順序。

## v14 修正
- 新增「📝 備忘錄」區域，為固定區域。
- 備忘錄可保存文字內容、其他網址與可編輯表格。
- 食物、購物、影劇、生活管理、備忘錄都加入圖片附件。
- 圖片附件在使用者主動選擇前會先顯示同意提示；瀏覽器不會讓網站自行讀取整個相簿，只有使用者在系統選擇器中選取的圖片才會交給網站。
- 新增 Supabase Storage attachments bucket 與個人資料權限。


## v15 修正與新增
- 📝 備忘錄維持為首頁固定的第五個區域。
- 表格可持續新增欄與列；文字、圖片附件與網址沒有網站端設定的數量上限。
- 👥 備忘錄與生活管理新增「共用」功能：可建立多個群組、設定群組名稱與密碼，也可加入別人提供的群組。
- 私人資料與共用資料並存；所有五個區域都可切換到個人或共用群組空間。
- 共用群組採名稱＋密碼加入；同一帳號可以同時加入兩個、三個或更多群組。
- 共用資料的圖片附件也會依群組權限讓成員查看。


## v25
- 五個區域的內建分類與自訂分類都可以新增、刪除與拖曳調整順序。
- 新增按鈕統一為「＋ 新增」。
- 所有刪除分類、內容、照片、表格列／欄與退出群組的操作，都會先顯示「是／否」確認視窗。
- 以初始化標記避免已刪除的內建分類在重新載入時自動恢復。

# My Little Space
明亮奶油米白＋粉紫藍綠柔和漸層。
食物：日式、韓式、義式、咖啡廳、餐酒館、其他。
購物：台灣、日本、其他。
影劇：韓劇、陸劇、電影。
生活管理：提醒事項、行程。
不包含 App／桌面捷徑功能。


使用者名稱：每個帳號預設顯示 `user`，可由使用者自行修改；修改後只保存於自己的帳號。

- 生活管理圖示：🧩

## v15 修正與新增

## v32 更新

## v36 操作流程優化
- 資料夾新增與編輯改為網站內表單，不再跳出瀏覽器 prompt；名稱必填，備註可留白。
- 批次照片新增會先檢查所有必填名稱，避免空白資料被默默略過。
- 批次儲存逐張顯示狀態與進度；中途失敗可直接重試，已建立的資料不會再次新增。
- 若圖片上傳成功但附件資料寫入失敗，會嘗試清理未完成的 Storage 檔案，降低殘留檔案。
- 卡片與資料夾新增上下移動按鈕，手機不支援拖曳時也能調整排序；原本桌面拖曳排序保留。
- 本版沒有新增資料表或欄位，不需要重新執行 Supabase SQL。直接以本版檔案覆蓋 GitHub Pages 專案即可。

注意：本版已完成程式語法與 ZIP 完整性檢查；實際登入、資料庫權限、Storage 上傳及不同手機瀏覽器仍需在你的 Supabase 專案與裝置上驗證。
